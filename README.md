# zeropentime

Открытая децентрализованная замена ZeroTier: **комнаты = виртуальные локальные сети**. Одно устройство может быть в нескольких комнатах одновременно.

- Шифрование и транспорт — **AmneziaWG 3** (форк WireGuard с защитой от DPI): Noise IK, Curve25519, ChaCha20-Poly1305 + PSK комнаты.
- Маскировка: защита заголовков AWG 3, случайные типы сообщений (H1–H4), паддинги (S1–S4), мусорные пакеты, content padding и скрытая метка комнаты вместо открытого номера.
- Все комнаты узла работают через **один UDP-порт**.

Документы: [архитектура](docs/ARCHITECTURE.md), [план реализации](docs/PLAN.md).

> Статус: **фаза 0**. Комнаты и пиры задаются статическим YAML. Контроллера, админ-панели, NAT traversal и exit-узлов пока нет — см. план.

## Сборка

```bash
go build -o zpt ./cmd/zpt
```

Нужен Go 1.26+. Windows: положите `wintun.dll` (с https://www.wintun.net, под свою архитектуру) рядом с `zpt.exe`.

## Быстрый старт (два устройства, одна комната)

На каждом устройстве:

```bash
zpt keygen -key node.key
```

На одном устройстве создайте комнату и передайте секрет второму участнику по защищённому каналу:

```bash
zpt room new
```

Заполните `zpt.yaml` по [примеру](deploy/examples/zpt.yaml), затем узнайте свой ключ в каждой комнате и обменяйтесь ключами с пирами:

```bash
zpt pubkey -c zpt.yaml
```

Запуск (Windows — от администратора, Linux — root или `CAP_NET_ADMIN`):

```bash
zpt up -c zpt.yaml
```

Проверка: `ping 10.100.1.2` с первого устройства.

> Windows помечает новые интерфейсы как «Общедоступная сеть» и блокирует входящий ping/SMB. Пока это не автоматизировано, разрешите нужное в брандмауэре или смените профиль сети интерфейса `zpt-<комната>` на «Частная».

## Тесты

```bash
go test ./...
```

Сквозной тест `internal/node` поднимает два узла с двумя комнатами на встроенном сетевом стеке (без прав администратора), пропускает трафик через «прослушивающий» прокси и проверяет, что:
- данные доходят в обеих комнатах, а комнаты изолированы;
- в перехваченных пакетах нет открытого текста;
- у пакетов нет постоянного префикса (сигнатуры для DPI);
- узел без разрешения или с неверным секретом комнаты не может подключиться.
