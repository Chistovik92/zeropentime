# Свой контроллер за 10 минут

Что получится: свой сервер управления комнатами с админ-панелью на вашем домене, HTTPS от Let's Encrypt, встроенные STUN и relay. Полное руководство — [GUIDE.md](GUIDE.md).

## Что нужно

- сервер с публичным IP и Docker (подойдёт самый дешёвый VPS с Linux);
- доменное имя, A-запись которого указывает на сервер, например `zpt.example.org`;
- в брандмауэре открыты **TCP 80, 443** и **UDP 3478, 3479, 3480**.

## Шаги

1. Скачайте проект и укажите домен:

   ```bash
   git clone https://github.com/Chistovik92/zeropentime.git && cd zeropentime
   export ZPT_DOMAIN=zpt.example.org
   ```

2. Запустите контроллер с Caddy (сертификат Let's Encrypt Caddy получит сам):

   ```bash
   docker compose -f deploy/docker-compose.yml up -d
   ```

3. Создайте администратора — команда напечатает пароль, сохраните его:

   ```bash
   docker compose -f deploy/docker-compose.yml exec controller zpt-controller useradd -db /data/controller.db -login admin -admin
   ```

4. Откройте `https://zpt.example.org`, войдите и **сразу смените пароль** и включите двухфакторный вход на странице своего логина («Мой аккаунт»).

5. Создайте комнату («Комнаты» → «Новая комната») и приглашение («Создать приглашение»). Ссылка `zpt://…` показывается один раз — отправьте её участнику.

6. Участник ставит `zpt` ([установка](GUIDE.md#3-узел-установка)) и открывает ссылку. Если комната «с одобрением», нажмите «Одобрить» в панели.

## Не забудьте

- **Ключ шифрования базы.** Без него копия базы раскрывает ключи ваших комнат. Создайте ключ и подключите его ([как](GUIDE.md#ключ-шифрования-и-резервные-копии)) до того, как заведёте важные комнаты.
- **Резервные копии.** `zpt-controller backup -db … -out …` по cron или кнопка на странице «Журнал». Копия ключа — отдельно от копии базы.
- **Обновления.** Образ нового релиза: `docker compose -f deploy/docker-compose.yml pull && docker compose -f deploy/docker-compose.yml up -d`. База мигрирует сама.
- **Ограничения** на публичном сервере: `serve -max-rooms 3 -max-members 50` не даст одному пользователю или комнате занять ресурсы.
- **Единый вход** через Google, Keycloak, Authentik — [раздел «Панель»](GUIDE.md#вход-в-панель-двухфакторный-и-через-oidc).

## Проверка, что всё работает

- страница панели открывается по HTTPS без предупреждений браузера;
- у участника `zpt status` показывает комнату и пиров; в панели у участника зелёная точка;
- на странице «Обзор» видно, сколько устройств в сети и какая доля соединений прямая.

Если что-то не так — [раздел «Если что-то не работает»](GUIDE.md#18-если-что-то-не-работает).
