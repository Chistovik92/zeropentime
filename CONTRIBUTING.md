# Как внести вклад

Спасибо, что помогаете zeropentime!

## Подпись DCO

Мы используем [Developer Certificate of Origin 1.1](https://developercertificate.org/) вместо CLA. Подписывая коммит, вы подтверждаете, что имеете право передать этот код и передаёте его под лицензией изменяемого файла (MPL-2.0 или AGPL-3.0, см. [LICENSING.md](LICENSING.md)). Права на ваш код остаются за вами.

Каждый коммит в pull request должен содержать строку

```
Signed-off-by: Имя Фамилия <email@example.org>
```

Git добавляет её сам:

```bash
git commit -s
```

Проверка выполняется в CI для каждого pull request.

## Перед pull request

```bash
gofmt -l .
go vet ./...
go test ./...
```

- Новый файл начинается со строки `SPDX-License-Identifier` с лицензией его директории (тест `internal/licensecheck` напомнит).
- Узел (`cmd/zpt` и всё, что он импортирует) не должен зависеть от AGPL-пакетов.
- Изменения, заметные пользователю, — запись в разделе «Не выпущено» в [CHANGELOG.md](CHANGELOG.md).
- Сообщения коммитов и документация — на русском; идентификаторы и комментарии в коде — на английском.

## Уязвимости

Не открывайте публичный issue для уязвимостей — см. [SECURITY.md](SECURITY.md).
